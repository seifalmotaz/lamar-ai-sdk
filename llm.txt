# Lamar AI SDK - Usage Reference

Lamar SDK is a Go alternative to Vercel's TypeScript AI SDK, providing a unified, type-safe interface for building AI applications with LLMs.

## Quick Start

**One-line description:** Type-safe Go SDK for AI models with a unified interface across providers.

**Installation:**
```
go get github.com/seifalmotaz/lamar-ai-sdk
```

**Requirements:** Go 1.23+

**Minimal example:**
```go
import (
    "context"
    "github.com/seifalmotaz/lamar-ai-sdk/providers/openai"
    "github.com/seifalmotaz/lamar-ai-sdk/generate"
)

func main() {
    client := openai.NewProvider()
    model := client.GPT5Mini()
    
    result, err := generate.Generate(context.Background(), model, "Hello, world!")
    if err != nil {
        panic(err)
    }
    println(result.Text())
}
```

## Text Generation (`generate` package)

**Import:** `github.com/seifalmotaz/lamar-ai-sdk/generate`

**Function:**
```go
func Generate(ctx context.Context, model provider.Generator, prompt string, opts ...Option) (*Result, error)
```

**Options:**
```go
System(prompt string)              // System prompt
Messages(msgs ...provider.Message) // Conversation history
MaxTokens(n int)                  // Max tokens to generate
Temperature(t float64)            // Randomness (0.0-2.0)
TopP(p float64)                   // Nucleus sampling (0.0-1.0)
TopK(k int)                       // Top-k sampling
StopSequences(seqs ...string)     // Stop sequences
Tools(tools ...provider.ToolDefinition) // Available tools
ToolChoice(tc provider.ToolChoice)      // Tool choice strategy
Seed(seed int)                    // Deterministic sampling
ResponseFormat(rf provider.ResponseFormat) // Response format
WithTimeout(d time.Duration)      // Custom timeout
WithNoTimeout()                   // Disable timeout
WithLogger(l provider.Logger)      // Logger
WithMetrics(m provider.MetricsCollector) // Metrics
```

**Result methods:**
```go
result.Text() string
result.Content() []provider.Content
result.ToolCalls() []provider.ToolCall
result.FinishReason() provider.FinishReason
result.Usage() provider.Usage
```

**Example:**
```go
result, err := generate.Generate(ctx, model, "Explain Go in simple terms",
    generate.MaxTokens(500),
    generate.Temperature(0.7),
)
```

## Streaming Generation (`stream` package)

**Import:** `github.com/seifalmotaz/lamar-ai-sdk/stream`

**Function:**
```go
func Stream(ctx context.Context, model provider.Streamer, prompt string, opts ...Option) *Result
```

**Options:** Same as `generate` package (System, Messages, MaxTokens, Temperature, TopP, TopK, StopSequences, Tools, ToolChoice, Seed, ResponseFormat, WithTimeout, WithNoTimeout, WithLogger, WithMetrics)

**Result methods:**
```go
result.Stream() <-chan provider.StreamPart     // Consume stream parts
result.Text() (string, error)                  // Get full text
result.Usage() (provider.Usage, error)         // Get usage stats
result.FinishReason() (provider.FinishReason, error) // Get finish reason
result.Err() error                             // Get any error
result.Wait() <-chan struct{}                 // Wait for completion
```

**Stream part types (type switch on StreamPart):**
```go
provider.StreamTextPart{Delta string}      // Text chunk
provider.StreamToolCallPart{ToolCall provider.ToolCall} // Tool call
provider.StreamFinishPart{FinishReason, Usage}         // Completion
provider.StreamErrorPart{Error error}       // Error
```

**Example:**
```go
result := stream.Stream(ctx, model, "Tell me a story")

for part := range result.Stream() {
    switch p := part.(type) {
    case provider.StreamTextPart:
        fmt.Print(p.Delta)
    case provider.StreamFinishPart:
        fmt.Println("\nFinished:", p.FinishReason)
    case provider.StreamErrorPart:
        log.Printf("Error: %v", p.Error)
    }
}
```

## Structured Output

**Import:** `github.com/seifalmotaz/lamar-ai-sdk/generate` or `github.com/seifalmotaz/lamar-ai-sdk/stream`

**Non-streaming:**
```go
func GenerateObject[T any](ctx context.Context, model provider.Generator, prompt string, opts ...Option) (*ObjectResult[T], error)

type ObjectResult[T any] struct {
    Object       T
    FinishReason provider.FinishReason
    Usage        provider.Usage
}
```

**Streaming:**
```go
func StreamObject[T any](ctx context.Context, model provider.Streamer, prompt string, opts ...Option) *StreamObjectResult[T]

type StreamObjectResult[T any] struct {
    // Methods:
    Stream() <-chan ObjectPart[T]
    Object() (T, error)
    Text() (string, error)
    Usage() (provider.Usage, error)
    FinishReason() (provider.FinishReason, error)
    Err() error
    Wait() <-chan struct{}
}

type ObjectPart[T any] struct {
    Type   string  // "object", "text-delta", "error", "finish"
    Object T       // Parsed object
    Delta  string  // Text delta
    Error  error   // Error if type="error"
}
```

**jsonschema tags:**
```go
required        // Field is required
description     // Field description
minimum         // Min number value
maximum         // Max number value
minLength       // Min string length
maxLength       // Max string length
enum            // Enum values
minItems        // Min array items
maxItems        // Max array items
```

**Example:**
```go
type Person struct {
    Name        string   `json:"name" jsonschema:"required,description=Full name"`
    Age         int      `json:"age" jsonschema:"required,minimum=0"`
    Occupation  string   `json:"occupation" jsonschema:"description=Job title"`
    Skills      []string `json:"skills" jsonschema:"minItems=1"`
}

// Non-streaming
result, err := generate.GenerateObject[Person](ctx, model, "Generate a random person")
fmt.Println(result.Object.Name, result.Object.Age)

// Streaming
streamResult := stream.StreamObject[Person](ctx, model, "Generate a person")
for part := range streamResult.Stream() {
    if part.Type == "object" {
        fmt.Printf("Partial: %+v\n", part.Object)
    }
}
final, err := streamResult.Object()
```

## Tool/Function Calling (`tool` package)

**Import:** `github.com/seifalmotaz/lamar-ai-sdk/tool`

**Create a type-safe tool:**
```go
func NewTool[In, Out any](name, description string, fn func(ctx context.Context, input In) (Out, error)) Tool

// Tool interface:
type Tool interface {
    Name() string
    Description() string
    InputSchema() json.RawMessage
    Execute(ctx context.Context, input json.RawMessage) (json.RawMessage, error)
}
```

**Convert to definitions for generate options:**
```go
func ToDefinition(t Tool) provider.ToolDefinition
func ToDefinitions(tools ...Tool) []provider.ToolDefinition
```

**Result helpers:**
```go
func SuccessResult(data interface{}) json.RawMessage   // {"success": true, "data": ...}
func ErrorResult(errorType, message string) json.RawMessage // {"success": false, "error": "...", "message": "..."}
```

**Tool choice constructors:**
```go
provider.ToolChoiceAuto()       // Model decides
provider.ToolChoiceNone()       // No tools
provider.ToolChoiceRequired()   // Must call tool
provider.ToolChoiceNamed(name)   // Call specific tool
```

**Example:**
```go
// Define tool
type WeatherInput struct {
    City string `json:"city" jsonschema:"required"`
}

type WeatherOutput struct {
    Temperature float64 `json:"temperature"`
    Condition  string  `json:"condition"`
}

weatherTool := tool.NewTool[WeatherInput, WeatherOutput](
    "get_weather",
    "Get current weather for a location",
    func(ctx context.Context, input WeatherInput) (WeatherOutput, error) {
        return WeatherOutput{Temperature: 22.5, Condition: "sunny"}, nil
    },
)

// Use in generate
result, err := generate.Generate(ctx, model, "What's the weather in Tokyo?",
    generate.Tools(tool.ToDefinitions(weatherTool)...),
    generate.ToolChoice(provider.ToolChoiceAuto()),
)

// Handle tool calls
for _, tc := range result.ToolCalls() {
    fmt.Printf("Tool: %s, Input: %s\n", tc.Name, string(tc.Input))
    
    // Execute tool and create result message
    toolResult := tool.SuccessResult(map[string]any{"temp": 22.5})
    // Use tool.NewToolCallContent and provider.NewToolResultContent to build messages
}
```

## Agent Framework (`agent` package)

**Import:** `github.com/seifalmotaz/lamar-ai-sdk/agent`

**Creation:**
```go
func New(model provider.LanguageModel, opts ...Option) *Agent
```

**Agent options:**
```go
WithTools(tools ...tool.Tool)                  // Available tools
WithStopWhen(conditions ...StopCondition)       // Stop conditions
WithSystem(system string)                       // System prompt
WithToolChoice(choice provider.ToolChoice)      // Tool choice
WithTemperature(temp float64)                  // Temperature
WithMaxTokens(tokens int)                      // Max tokens
WithMaxRetries(n int)                          // Max retries (default: 2)
WithCallbacks(cb Callbacks)                    // Callbacks
WithPrepareStep(fn PrepareStep)                // Dynamic config per step
WithExperimentalContext(ctx any)              // Custom context
```

**Stop conditions:**
```go
func StepCountIs(n int) StopCondition              // Stop after n steps
func HasToolCall(name string) StopCondition         // Stop when tool called
func HasFinishReason(reasons ...provider.FinishReason) StopCondition
func StopWhenAny(conditions ...StopCondition) StopCondition  // OR logic
func StopWhenAll(conditions ...StopCondition) StopCondition // AND logic
```

**Synchronous execution:**
```go
func (a *Agent) Invoke(ctx context.Context, opts ...InvokeOption) (*Result, error)

type InvokeOption func(*invokeConfig)
func WithMessages(messages ...provider.Message) InvokeOption
func WithInvokeSystem(system string) InvokeOption
```

**Streaming execution:**
```go
func (a *Agent) Stream(ctx context.Context, opts ...StreamOption) <-chan StreamEvent

type StreamOption func(*streamConfig)
func WithStreamMessages(messages ...provider.Message) StreamOption
func WithStreamSystem(system string) StreamOption
func WithStreamCallbacks(cb Callbacks) StreamOption
```

**Callbacks struct:**
```go
type Callbacks struct {
    OnStart           func(ctx context.Context, messages []provider.Message) error
    OnStepStart       func(ctx context.Context, stepNumber int, messages []provider.Message) error
    OnStepFinish      func(ctx context.Context, result StepResult) error
    OnToolCallStart   func(ctx context.Context, toolCall provider.ToolCall) error
    OnToolCallFinish  func(ctx context.Context, result ToolExecutionResult) error
    OnFinish          func(ctx context.Context, result *Result) error
    OnError           func(ctx context.Context, stepNumber int, err error) error // Return nil to suppress and continue
}
```

**Stream events (type switch):**
```go
StreamEventStepStart{StepNumber int, Messages []provider.Message}
StreamEventContentDelta{Delta string}
StreamEventToolCall{ToolCall provider.ToolCall}
StreamEventToolResult{Result ToolExecutionResult}
StreamEventStepFinish{Result StepResult}
StreamEventFinish{Result *Result}
StreamEventError{Error error}
```

**Results:**
```go
type Result struct {
    Steps         []StepResult
    FinalMessages []provider.Message
    FinalContent  []provider.Content
    FinalText     string
    TotalUsage    provider.Usage
    TotalDuration time.Duration
    FinishReason  provider.FinishReason
}

type StepResult struct {
    StepNumber   int
    Content      []provider.Content
    ToolCalls    []provider.ToolCall
    ToolResults  []ToolExecutionResult
    Usage        provider.Usage
    FinishReason provider.FinishReason
    Model        ModelInfo
    Duration     time.Duration
}

type ToolExecutionResult struct {
    ToolCallID, ToolName string
    Input, Output        any
    Error                error
    Duration             time.Duration
}
```

**PrepareStep for dynamic configuration:**
```go
type PrepareStep func(ctx context.Context, params PrepareStepParams) *PrepareStepResult

type PrepareStepParams struct {
    StepNumber      int
    Steps           []StepResult
    Model           provider.LanguageModel
    Messages        []provider.Message
    ToolCalls       []provider.ToolCall
    ExperimentalCtx any
}

type PrepareStepResult struct {
    Model        provider.LanguageModel
    Tools        []tool.Tool
    ToolChoice   *provider.ToolChoice
    System       *string
    MaxTokens    *int
    Temperature  *float64
    ExperimentalCtx any
}
```

**Example:**
```go
// Create agent
ag := agent.New(model,
    agent.WithTools(weatherTool, calculatorTool),
    agent.WithStopWhen(
        agent.StopWhenAny(
            agent.StepCountIs(10),
            agent.HasToolCall("submit_answer"),
        ),
    ),
    agent.WithCallbacks(agent.Callbacks{
        OnStepFinish: func(ctx context.Context, step agent.StepResult) error {
            log.Printf("Step %d completed", step.StepNumber)
            return nil
        },
    }),
)

// Invoke
result, err := ag.Invoke(ctx,
    agent.WithMessages(provider.UserMessage("What's the weather in Tokyo and New York?")),
)

// Stream
stream := ag.Stream(ctx,
    agent.WithStreamMessages(provider.UserMessage("Tell me a story")),
)
for event := range stream {
    switch e := event.(type) {
    case agent.StreamEventStepStart:
        fmt.Printf("Step %d starting\n", e.StepNumber)
    case agent.StreamEventToolCall:
        fmt.Printf("Tool: %s\n", e.ToolCall.Name)
    case agent.StreamEventFinish:
        fmt.Println("Final:", e.Result.FinalText)
    case agent.StreamEventError:
        log.Printf("Error: %v", e.Error)
    }
}
```

```go
handler := middleware.Chain(
    middleware.Recover(),
    middleware.Logging(logger),
    middleware.Metrics(collector),
    middleware.Retry(middleware.RetryConfig{
        MaxAttempts:  3,
        InitialDelay: time.Second,
        MaxDelay:     30 * time.Second,
        RetryOn: func(err error) bool {
            return provider.IsRateLimited(err) || provider.IsTimeout(err)
        },
    }),
)(baseHandler)

// Custom middleware
func CustomMiddleware(name string) middleware.Middleware {
    return func(next middleware.Handler) middleware.Handler {
        return middleware.HandlerFunc(func(ctx context.Context, req middleware.Request) (middleware.Response, error) {
            // Pre-processing
            resp, err := next.Handle(ctx, req)
            // Post-processing
            return resp, err
        })
    }
}
```
